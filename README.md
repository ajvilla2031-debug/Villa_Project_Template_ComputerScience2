# Personal Expense and Budget Tracker

A Python based console application designed to help students and families record daily purchases, categorize expenses, and monitor their remaining allowance in real time.

## Repository Structure
* `/data` Folder reserved for storing structured expense records and datasets.
* `/docs` Contains the project proposal draft (`proposal_template.md`) and planning documentation.
* `README.md` Project overview and repository guide.

## Key Features
* **Allowance Setup: Enter a starting budget to track spending against.
* **Expense Logging: Record purchase amounts and categories with automatic date and time stamps.
* **Transaction History: View a full list of past recorded expenses.
* **Category Filtering: Search and display expenses under a specific category such as Food or Transport.
* **Budget Summary: automatically calculates total spent and remaining balance.
